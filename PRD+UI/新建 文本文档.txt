模块1：地图基础功能
- 功能描述：加载百度地图底图，支持基础操作和搜索。 支持鼠标滚轮缩放地图，拖拽地图平移，左上角搜索框支持输入关键词，调用百度地图POI检索API，返回结果并在地图上标记点位，点击点位显示简要信息。

模块2：路线规划功能
自动规划
- 功能描述：输入起点、终点、途经点，选择出行方式，生成路线；支持在现有路线各点位之间插入途经点，并为所有点位设置游玩顺序（优先级）。
- 交互逻辑：
- 左侧路线编辑栏，新增路线图层，输入起点、终点（支持搜索选择POI，或直接在地图上点击选择点位），添加初始途经点（最多10个），可调整途经点顺序。
- 选择出行方式（步行/驾车/公共交通/骑行），点击“生成路线”按钮，地图上显示路线折线及所有点位。
-支持两个地点之间设置特定出行方式，如：地点1,2之间骑行，地点2,3之间公共交通，地点3,4之间步行。

模块3：图层管理功能
- 功能描述：为每条路线创建独立图层，支持图层管理操作。
交互逻辑：
  - 路线生成后，自动创建对应图层（默认名称为“路线1”“路线2”...），图层颜色随机区分（不重复）。
  - 左侧图层管理栏，显示所有已创建的图层，每个图层对应“复选框（显示/隐藏）”“重命名按钮”“删除按钮”。
  - 勾选复选框，地图上显示该图层的路线；取消勾选，隐藏该图层路线。
  - 点击“重命名”，可修改图层名称（如“成都三日游”）；点击“删除”，弹出确认框，确认后删除该图层及对应路线。
  - 支持同时显示多个图层路线，折线不重叠、颜色区分明显。

模块4：路线编辑与保存
- 功能描述：编辑路线信息，保存路线到本地，查看历史路线。
交互逻辑：
  - 路线生成后，右侧编辑栏可输入路线名称、出行天数、备注（可选），同时显示所有点位列表，支持调整点位顺序、添加/删除途经点、设置点位优先级。
  - 点击“保存路线”按钮，将路线信息（名称、天数、备注、路线坐标、图层信息、点位优先级/游玩顺序）保存到浏览器本地缓存。
  - 点击首页“历史路线”，进入历史路线页，展示所有保存的路线（显示路线名称、出行天数、缩略图、核心点位及优先级概况）。
  -点击历史路线，可进入详情页，查看路线完整信息、地图预览（标注点位优先级/顺序），支持编辑（调整途经点、修改优先级）、删除。

npm ci
npm run build

# 4) 发布（按你的 Nginx root 选择一种）

sudo rsync -av --delete dist/ /usr/share/nginx/html/

# 5) 检查并重载 Nginx
sudo nginx -t
sudo systemctl reload nginx
